# LinkedIn Ad Copy

This skill writes B2B LinkedIn ad copy by testing **different strategic bets**, not rewordings of one idea. Five versions of "we're faster" is one bet placed five times, and when it loses you learn nothing. The method below is built so that every ad in a test tells the advertiser something different about their audience.

Method source: Get Wicked Growth's LinkedIn ad creative playbook, plus a set of classic and modern B2B copy frameworks (see `references/frameworks.md`).

## Workflow

Run these steps in order. For a narrow request ("just give me hooks for this angle"), jump to the step that fits, but keep the rules at the bottom.

### 1. Build the input pack

Output quality is capped by input quality. Collect:

- **Positioning**: one line on what the product is and who it's for
- **Differentiators**: top 3, stated concretely ("syncs in under 5 minutes"), not aspirationally ("best-in-class")
- **Persona**: title, industry, company size, what they care about, what they worry about
- **Customer quotes**: 3-5 verbatim phrases customers used to describe their own pain
- **Offer and destination**: what the click leads to (demo, gated asset, webinar, trial) and the funnel stage

Ask for whatever is missing in one compact message, not one question at a time. If the user has files, a website, or earlier campaigns, read those first and only ask about the gaps. If the user has told you to go ahead with what they gave you, don't block on small gaps like funnel stage: pick a sensible default, state the assumption in one line at the top of the output, and continue. Only stop to ask when positioning or persona is missing, because everything downstream depends on them.

Customer quotes are raw material for hooks, not necessarily publishable testimonials. When a quote appears in the copy, flag that the user should confirm attribution or permission. A figure inside a quote ("half the week") is a customer's perception, not a measured stat, so frame it as their words or swap in a verified number.

**If there are no real quotes**, mine them: search for how the persona describes the pain on G2/Capterra reviews, Reddit, practitioner forums, and community threads. Prefer unflattering, specific phrasing ("I spend my whole Friday rebuilding the same forecast") over polished language. List each quote with its source URL. Customer phrasing beats anything invented in-house, which is why this step is worth the time. Never fabricate a quote or a statistic and present it as real. If a number is needed and unverified, write it as a placeholder like `[X hours/week]` and flag it.

If the positioning is vague or the differentiation is a guess, say so and sharpen it with the user first (April Dunford's five components in `references/frameworks.md`). Angles built on fuzzy positioning are guesses about differentiation.

### 2. Generate 8 distinct angles, then cut to 4-5

An angle is a strategic premise about why the reader should care. Draw each from a **different** premise in this menu:

cost of inaction · contrarian take · status-quo critique · specific quantified outcome · identity/status · risk reduction · speed · peer/social proof · problem reframing

The test: every angle must be arguable *against* the others. If two angles can't disagree, they're one angle in two outfits. Use a premise once.

Tag each angle with the **awareness level** it targets (Unaware, Problem-Aware, Solution-Aware, Product-Aware, Most Aware). Different awareness levels need different angles, so this is a good check that the set is varied, and it drives the copy structure in step 3.

Per angle give: **name**, **premise** (one sentence on why it works psychologically), **core claim**, **source quote or pain**, **awareness level**.

Then do a redundancy check: name any two angles that are secretly the same bet, replace one, and recommend the 4-5 most distinct. Two angles that lean on the same quote and send readers to the same place are usually one bet, so check those pairs hardest. If an angle needs proof the user hasn't supplied (a win rate, a named customer), bench it and say what's needed to unlock it. More than 5 splits budget too thin to read results. The rest go on the bench for the next round. Show the full 8 plus your recommended 5 and why.

### 3. Write hooks and copy for each recommended angle

Per angle, produce:

1. **Three hook variants.** Each must deliver its tension or payoff inside **140 characters**, because LinkedIn truncates at about 140-150 behind "see more" and most people, especially on mobile, never click. If the point arrives after the cut, the ad fails no matter how good the full line reads. Mark one hook as the pick to launch. The other two are reserve lines for the hook-level round. Only the picked hook gets full intro text and carousel; write full copy for a reserve hook in round 2 once an angle has won.
2. **Intro text** under 600 characters, built on the picked hook (it should open with the hook). Specific and concrete throughout.
3. **Headline** for the ad card, kept short (about 70 characters or fewer so it doesn't truncate).
4. **4-slide carousel outline**, one line per slide, telling this angle's story.
5. **CTA matched to the angle**: a closing line in the copy plus the button label, chosen from LinkedIn's preset buttons (Learn more, Sign up, Request demo, Download, Register and so on). A cost-of-inaction angle ("See where the 9 hours actually go →") and a peer-proof angle ("See how [peer companies] solved this →") earn different actions. Never reuse one CTA across all angles. Match the ask to temperature: cold, low-awareness angles get a low-friction ask (guide, trial, short video), warm angles can ask for the demo.

Pick the copy structure from the angle and its awareness level (details and when-to-use in `references/frameworks.md`):

| Awareness | Usually works | Structure |
|---|---|---|
| Unaware | Pattern-interrupt story, native-feeling post | BAB or first-person narrative |
| Problem-Aware | Agitation, cost of inaction | PAS |
| Solution-Aware | Mechanism proof, why the old way fails | QUEST or PASTOR (carousel) |
| Product-Aware | Differentiation, comparison | FAB-led benefit, proof |
| Most Aware | Offer and low-friction CTA | AIDA, short |

Name the structure used for each ad in the output so the user can see what is being tested.

For 1-2 angles, also offer a **native-voice variant**: first person, plain text, reads like a post a real person would write rather than a banner ad. B2B audiences have ad-blindness and native-feeling creative tends to get past it. Top-of-funnel angles benefit most. Direct-offer angles should stay direct. A native-voice variant changes voice and format on top of the angle, so keep it out of the round-1 angle test and run it as its own test or as a thought-leader ad. Don't count it toward the 4-5.

### 4. Spec the creative

Copy and visual have to reinforce the same premise, or they cancel each other. A sharp contrarian hook over a smiling stock photo undoes both. For each angle give:

- **Visual concept** that expresses *this* angle, not a generic version
- **On-image headline**, under 8 words
- **Format**: stat card, side-by-side comparison, annotated screenshot, bold-text treatment, or simple illustration. These almost always beat a stock photo of people pointing at laptops.
- **Color and emotional tone** (stark and serious for cost of inaction)
- **Avoid**: be specific ("no stock photos of people at laptops, no abstract swooshes")
- **Size**: 1200x627 or 1080x1080 for single image

### 5. Output the test matrix and launch advice

Give one row per round-1 ad (one per recommended angle, using the launch hook) with columns: Angle, Premise, Awareness level, Launch hook, Reserve hooks (B/C), Format, Intro text, CTA, Creative brief, Audience, Results (spend, impressions, CTR, CPL, conversions), **Learning**. Leave results and learning blank. Round 2 adds rows for the winning angle's hook variants. Offer to save it as a CSV the user can import to Google Sheets.

Launch advice to include in a short note:

- Round 1: 4-5 angles, one strong hook each, **same audience and budget** so angle is the only variable
- Don't judge on one or two days of thin data. Small B2B audiences collect clicks slowly, and an early kill may remove the eventual winner.
- Kill clear losers, then round 2: expand hook variants under the winning angle only. Test one variable at a time.
- Log a plain-language learning per variant ("cost-of-inaction beat feature-superiority 2:1 on CTR with this persona"). That column becomes the map of what this audience responds to.

If the user comes back with results, feed the winning angle and real metrics into the next generation round.

## Rules for the copy itself

- **Banned words**: unlock, leverage, supercharge, seamless, game-changer, revolutionize, effortless. They read as generic or AI-written and trigger a scroll.
- **Banned openers and patterns**: "Are you struggling with...", fake-vulnerability hooks, clickbait questions, engagement bait.
- **Clarity over clever.** Say what it is, who it's for, and the outcome plainly before being witty. Wit goes in the supporting line.
- **Specific beats abstract.** Real numbers, named outcomes, the persona's own words. Use the 4 Us (useful, urgent, unique, ultra-specific) to score hooks.
- **Customer as hero.** The reader is the protagonist and the brand is the guide.
- **Never invent proof.** No made-up stats, customers, or quotes. Use `[placeholders]` and flag them.
- Ads for different premises should not read like siblings. If two hooks share a sentence skeleton, rewrite one.

## Quality gate before delivering

1. Run `scripts/check_copy.py` on the drafted ads. It counts hook and intro characters and flags banned words and openers. Fix anything it flags, then re-run. Usage: `python3 scripts/check_copy.py ads.json` (format in the script's docstring), or pass `--hook "..."` for a single check.
2. Pass each ad through the **4 Cs** (clear, concise, compelling, credible). Is the claim backed by something real?
3. Check the **message layers** in order: does a stranger know what it is (clarity), that it's for them (relevance), why they'd want it (value), why you (differentiation)?
4. Load and apply the `stop-slop` skill to the prose and revise if it falls short of its threshold. Ad copy is exactly where AI tells cost you clicks. Apply it to word choice, filler, hedging, and stock phrasing. Ad conventions it wasn't written for are fine: sentence fragments, imperative CTAs, and a short contrast line in a hook. You don't need to print a score, just deliver the revised copy.
5. Check the copy against the checker's blind spots yourself: CTA length, whether the intro opens with the hook, and whether any hook is a question that reads as engagement bait.

## Output format

Lead with the angle table (8, with 4-5 marked as recommended). Then one block per recommended angle:

```
### Angle: [name]  ·  Premise: [premise]  ·  Awareness: [level]  ·  Structure: [PAS/BAB/...]
Core claim: ...
Source pain/quote: "..." (source)

Hooks (char count)
A (118): ...   ← launch this one
B (131): ...
C (96): ...

Intro text (412 chars): ...
Headline: ...
CTA: closing line · button label
Carousel: 1) ... 2) ... 3) ... 4) ...
Native-voice variant (optional): ...

Creative: format · visual concept · on-image headline · tone · avoid
```

Put assumptions and anything the user must confirm (placeholders, quote permissions) in two or three lines before the angle table. Close with the test matrix and the short launch note. Keep commentary tight. The user came for ads, so the ads should dominate the response.
